### 🚀 Featured Projects

<details>
<summary><b>🛡️ SafeRoute — Multi-Signal Safety Navigation PWA</b></summary>
<br/>

A real-time safety navigation Progressive Web App that ranks route candidates using a weighted, multi-signal risk-scoring model instead of relying on distance/time alone.

| | |
|---|---|
| **Stack** | React · Node.js · Express · MongoDB Atlas · Socket.io · OSRM · Nominatim · Overpass API |
| **Scale** | Real-time GPS tracking with live coordinate synchronization across active sessions |
| **Security** | JWT authentication, bcrypt password hashing, session-scoped API access |
| **Impact** | Ranked 18/60 teams (Top 30%) at HackMol 7.0, NIT Jalandhar |
| **Repository** | [SafeRoute →](https://github.com/shivamsharma75/saferoute) |

Built as an installable PWA with offline caching, SafeRoute combines crowdsourced incident data, OpenStreetMap metadata, and time-of-day risk factors into a single safety score per route. SOS broadcasting and live location sharing run over Socket.io, backed by a MongoDB Atlas persistence layer and a RESTful API layer for route logic and session state.

</details>

<details>
<summary><b>⚡ SiteForge AI — AI Website Generation Platform</b></summary>
<br/>

A full-stack platform that generates deployable websites from user prompts, routing generation requests across multiple LLM providers and handling end-to-end monetization.

| | |
|---|---|
| **Stack** | React · Node.js · Firebase · Stripe · OpenRouter API (Claude, Gemini, GPT) |
| **Scale** | Runtime API-injection pipeline connecting AI-generated forms to a live MongoDB lead dashboard |
| **Security** | Dual-mode Firebase Admin + custom JWT authentication, idempotent Stripe webhook handling |
| **Impact** | Fully shipped, deployed platform — not a tutorial clone |
| **Repository** | [SiteForge AI →](https://github.com/shivamsharma75/siteforge-ai) |

SiteForge AI dynamically routes generation requests across multiple LLM backends to balance cost, quality, and latency, then wires the generated site's forms directly into a real-time lead management dashboard. Payments run through a secure Stripe Checkout flow with idempotent webhook handling to prevent duplicate charges.

</details>
